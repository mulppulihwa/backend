| API | 제공 기관 | 내용 | 링크 |

## API 평가

### 행정안전부 보조금24 API (핵심)
- 중앙부처 + 지자체 혜택 통합 제공으로 커버리지 가장 넓음
- 서비스명, 지원내용, 신청자격, 신청방법, 담당기관 포함
- 귀농귀촌 + 노인 복지 모두 포함될 가능성 높음
- REST API, 인증키 신청 후 사용 가능

### 복지로 API (보완)
- 중앙부처 + 지자체 별도 API로 복지 특화 정보 상세
- 나이·가구유형 등 자격조건 데이터 포함 (Swagger UI로 명세 확인 가능)
- 보조금24 API에 없는 복지 서비스 보완용으로 활용

## 귀농귀촌 전용 API

- **귀농귀촌종합센터(returnfarm.com)**: 별도 공개 API 없음 — 웹 크롤링 또는 수동 입력 필요
- **농촌진흥청(nongsaro.go.kr)**: 공공데이터 개방 있으나 정책 지원 API보다는 농업 기술 데이터 중심
- **농어촌공사**: 공공데이터포털 통해 일부 개방, 귀농 자금 관련 별도 확인 필요

## 수집할 정책 출처

| 기관 | 접근 방법 | 정책 유형 |
|---|---|---|
| 행정안전부 (보조금24) | **공공 API** | 전체 혜택 서비스 통합 |
| 한국사회보장정보원 (복지로) | **공공 API** | 노인 복지, 중앙+지자체 |
| 귀농귀촌종합센터 | 수동 입력 | 귀농귀촌 특화 지원 |
| 농어촌공사 | 수동 입력 | 농지 임대, 창업 자금 |
| 각 광역자치단체 | 수동 입력 (우선 전남, 경북 등 귀농 많은 지역) | 귀농 장려금, 주택 지원 |

## 권장 데이터 전략

```
1단계 (MVP): 보조금24 API + 복지로 API로 기본 DB 구성
             귀농귀촌 특화 정책은 수동 입력 (20~30개)

2단계 (v2):  API 정기 동기화 스케줄러 구축
             returnfarm.com 크롤러 추가

3단계 (v3):  지자체별 소규모 사업 크롤링 확대
```
