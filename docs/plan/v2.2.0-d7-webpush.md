> 목표: 신청 마감 7일 전, 저장한 정책이 있는 사용자에게 브라우저 Web Push 알림 발송

## 0. 전체 흐름

```
[Django 백엔드]
  PushSubscription 모델
        │
  POST /api/notifications/subscribe/   ← 브라우저가 구독 정보 전송
        │
  send_d7_alerts 커맨드
        │  매일 09:00 KST = 00:00 UTC (Railway Cron)
        ▼
  UserPolicy 조회
    · policy.apply_end_date == today + 7일
    · d7_alerted_at IS NULL
    · status IN (신청예정, 신청완료)
        │
  pywebpush → 브라우저 Push API
        │
  d7_alerted_at = now() 저장

[Next.js 프론트엔드]
  /public/sw.js         — 서비스 워커 (push 이벤트 수신 + 알림 표시)
  hooks/useWebPush.ts   — 구독 허용 요청 + 백엔드 전송
  NEXT_PUBLIC_VAPID_KEY — .env.local에 설정 (API 호출 불필요)
```

```bash
# py-vapid CLI 설치 후
pip install py-vapid

# 키 생성 (private_key.pem 생성됨, 공개키는 stdout에 출력)
vapid --gen
# 출력 예시:
# Public Key:
# BN3...base64url...
# Private Key:
# base64url private key

# private_key.pem 내용을 Railway 환경변수에 등록 (줄바꿈은 \n으로)
# 또는 base64url private key를 VAPID_PRIVATE_KEY로 등록
```

Railway 환경변수:
- `VAPID_PRIVATE_KEY` — `vapid --gen` 출력의 Private Key (base64url)
- `VAPID_PUBLIC_KEY` — `vapid --gen` 출력의 Public Key (base64url)
- `VAPID_SUBJECT` — `mailto:admin@okcheonok.kr`

Next.js 환경변수 (`.env.local`, Vercel 대시보드):
- `NEXT_PUBLIC_VAPID_KEY` — `VAPID_PUBLIC_KEY` 와 동일 값 (프론트에서 직접 사용)

```python
class PushSubscribeView(APIView):
    permission_classes = [IsAuthenticated]

    def post(self, request):
        sub = request.data.get('subscription', {})
        endpoint = sub.get('endpoint')
        keys = sub.get('keys', {})
        if not endpoint or not keys.get('p256dh') or not keys.get('auth'):
            return Response({'error': 'subscription 형식이 올바르지 않습니다.'}, status=400)

        PushSubscription.objects.update_or_create(
            endpoint=endpoint,
            defaults={
                'user':   request.user,
                'p256dh': keys['p256dh'],
                'auth':   keys['auth'],
            }
        )
        return Response({'ok': True}, status=201)
```

파일: `apps/users/management/commands/send_d7_alerts.py`

```python
import json
import logging

from django.conf import settings
from django.core.management.base import BaseCommand
from django.utils import timezone
from pywebpush import WebPushException, webpush

from apps.users.models import PushSubscription, UserPolicy

logger = logging.getLogger(__name__)


class Command(BaseCommand):
    help = 'D-7 마감 정책 알림 발송'

    def handle(self, *args, **options):
        today = timezone.now().date()
        target_date = today + timezone.timedelta(days=7)

        user_policies = (
            UserPolicy.objects
            .filter(
                policy__apply_end_date=target_date,
                d7_alerted_at__isnull=True,
                status__in=[UserPolicy.Status.PENDING, UserPolicy.Status.APPLIED],
            )
            .select_related('policy', 'profile__user')
        )

        sent = failed = 0

        for up in user_policies:
            subscriptions = PushSubscription.objects.filter(user=up.profile.user)
            if not subscriptions.exists():
                up.d7_alerted_at = timezone.now()
                up.save(update_fields=['d7_alerted_at'])
                continue

            payload = json.dumps({
                'title': f'[마감 D-7] {up.policy.title}',
                'body': '신청 마감이 7일 남았습니다. 지금 확인하세요.',
                'url': f'/policies/{up.policy.id}',
            })

            for sub in subscriptions:
                try:
                    webpush(
                        subscription_info={
                            'endpoint': sub.endpoint,
                            'keys': {'p256dh': sub.p256dh, 'auth': sub.auth},
                        },
                        data=payload,
                        vapid_private_key=settings.VAPID_PRIVATE_KEY,
                        vapid_claims={'sub': settings.VAPID_SUBJECT},
                    )
                    sent += 1
                except WebPushException as e:
                    if e.response and e.response.status_code in (404, 410):
                        sub.delete()  # 만료된 구독 정리
                        logger.info('만료 구독 삭제: %s', sub.endpoint[:40])
                    else:
                        logger.warning('Push 발송 실패: %s', e)
                        failed += 1

            up.d7_alerted_at = timezone.now()
            up.save(update_fields=['d7_alerted_at'])

        self.stdout.write(
            self.style.SUCCESS(f'완료 — 발송: {sent}개, 실패: {failed}개')
        )
```

### 4-2. useWebPush 훅

파일: `hooks/useWebPush.ts`

```ts
// base64url → Uint8Array 변환 (Web Push 표준 헬퍼)
function urlBase64ToUint8Array(base64String: string): Uint8Array {
  const padding = '='.repeat((4 - (base64String.length % 4)) % 4);
  const base64 = (base64String + padding).replace(/-/g, '+').replace(/_/g, '/');
  const rawData = window.atob(base64);
  return Uint8Array.from([...rawData].map((c) => c.charCodeAt(0)));
}

export function useWebPush(accessToken: string) {
  const subscribe = async () => {
    if (!('serviceWorker' in navigator) || !('PushManager' in window)) {
      throw new Error('이 브라우저는 Web Push를 지원하지 않습니다.');
    }

    const reg = await navigator.serviceWorker.register('/sw.js');
    const publicKey = process.env.NEXT_PUBLIC_VAPID_KEY!;

    const sub = await reg.pushManager.subscribe({
      userVisibleOnly: true,
      applicationServerKey: urlBase64ToUint8Array(publicKey),
    });

    await fetch(`${process.env.NEXT_PUBLIC_API_URL}/api/notifications/subscribe/`, {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        Authorization: `Bearer ${accessToken}`,
      },
      body: JSON.stringify({ subscription: sub }),
    });
  };

  return { subscribe };
}
```
