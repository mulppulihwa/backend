# 문제 정의

> **귀농·귀향 초기에 정착하는 주민이 / 자격이 되는 지원을 신청 기간 내에 알지 못하는 문제를 해결하기 위해서는 / 개인의 상황에 맞게 정보를 번역해 적시에 전달하는 매개가 있어야 한다.**

**작성일**: 2026-04-15  
**방향**: 귀농·귀향 초기 정착 온보딩

---

## 핵심 문제 한 문장

> 귀농·귀향 초기 주민들은, 자신에게 해당되는 지원 정책이 존재함에도,  
> 그 정보가 적시에 자신에게 도달하는 구조가 없어서,  
> 신청 기간이 지난 뒤에야 알거나 영영 모르고 지나친다.

---

## 근거가 된 인터뷰

> *"자치단체에서 시행하는 청년 지원을 미리 알아보고 왔으면 하는 아쉬움이 있어요.*  
> *이사비용도 지원해주던데, 제가 이사한 후에 알게 되었어요."*  
> — 귀농민 인터뷰

이 발언이 중요한 이유:
- **정보가 없었던 게 아니다** — 정책은 존재했고, 자격도 됐다
- **신청 기회도 있었다** — 기간 내에 알았다면 받을 수 있었다
- **당사자가 직접 정보 공백을 체감했다** — 잠재 문제가 아닌 표현된 손실
- 이것이 가장 신뢰도 높은 데이터다

---

## 왜 이게 문제인가: 세 가지 걸림돌에 대한 정리

### 걸림돌 1 — "주민들이 불편함을 느끼지 않는다"

불편하다고 말하지 않은 이유가 중요하다.

| 이유 | 해석 |
|---|---|
| 비교 기준이 없어 격차를 격차로 인식 못함 | 잠재 문제 — 정의 가능 |
| 체념해서 기대 자체를 낮춤 | 잠재 문제 — 정의 가능 |
| 실제로 잘 해결되고 있음 | 문제 없음 |

인터뷰에서 이미 **알게 된 후 아쉬움을 직접 표현**했다. 즉, 모를 때는 불편함을 느끼지 못했지만 알게 됐을 때 손실을 인식했다. 이건 잠재 문제가 실재한다는 증거다.

**남은 검증 과제:**
- 이장이 확성기로 전달하는 정보가 무엇인가?
- 그 정보를 놓쳤을 때 크리티컬한 손실이 발생하는가?

### 걸림돌 2 — "삶의 방식을 침범하는 것 아닌가"

삶의 방식이라 부르려면 대안이 있었음에도 선택한 것이어야 한다.  
현재 단일 채널(이장 구두전달)은 선택한 것이 아니라, 다른 채널이 없어서 적응한 것이다.

우리는 기존 채널을 없애자는 게 아니다. **채널을 추가하는 것은 선택지 확장이지 파괴가 아니다.**

침범이 우려되는 지점은 문제 정의가 아니라 **솔루션 설계** 차원이다:
- 앱 강요, 기존 이장 역할 무시 → 침범
- 카카오 알림, 자녀 대리 접근, 복지사 연계 → 침범 아님

### 걸림돌 3 — 세 문제의 공통 근원

아래 세 문제를 종합하면, **정보 부재**가 아니라 **정보 전달 구조의 실패**다:

| 문제 | 표면 | 실제 원인 |
|---|---|---|
| 고령층이 정책 지원을 못 받음 | 정보 검색 능력 부족 | 맞춤 전달 구조 없음 |
| 마을 정보를 제때 못 받음 | 구두전달 단일 채널 | 채널 단일화·누적 불가 |
| 중요 정보를 모르고 지남 | 온라인 정보 찾기 어려움 | 개인 맥락으로 연결 안 됨 |

**공통 구조:**
- 정책은 있다
- 온라인에도 올라가 있다
- 그러나 당사자의 상황(나이, 지역, 이주 시점, 직종)에 맞게 **번역되어 전달되는 구조**가 없다
- 이장 구두전달은 단일하고, 누적되지 않고, 검색할 수 없다

## 문제 구조도

```
정책·지원이 존재한다
        ↓
중앙부처·광역·기초 지자체로 분산되어 있다
        ↓
공식 채널(온라인 포털, 이장 공지)로 배포된다
        ↓
[여기서 단절]
  - 온라인: 행정 리터러시·디지털 접근성 필요
  - 이장: 구두 전달 → 누락 가능, 누적 안 됨, 검색 불가
        ↓
당사자가 자신과 관련 있는지 판단하지 못한다
        ↓
신청 기간이 지난다 / 영영 모른다
        ↓
손실 발생 (받을 수 있었던 지원을 못 받음)
```

---

## 문제가 가장 크게 발생하는 시점

**귀농·귀향 직후 초기 정착기 (이주 후 1~6개월)**

- 새로운 지역의 지원 구조를 전혀 모르는 상태
- 이장·이웃 관계망에 아직 편입되지 않음
- 신청 기간이 있는 지원은 이 시기를 놓치면 1년을 기다려야 함
- 귀농 후 소득 발생까지 평균 3~5년 → 초기 재정 지원이 가장 절실한 시기

## 우리가 풀고자 하는 것 (플랫폼 이전 단계)

솔루션보다 먼저, 우리가 해결하고자 하는 상태 변화:

| 현재 상태 | 목표 상태 |
|---|---|
| 내가 어떤 지원을 받을 수 있는지 모른다 | 내 상황에 맞는 지원을 이주 초기에 파악한다 |
| 신청 기간이 지난 후에 알게 된다 | 신청 가능한 시점에 정보가 도달한다 |
| 정보를 찾으려면 행정 리터러시가 필요하다 | 묻고 답하는 것만으로 파악 가능하다 |
| 이장이 안 알려주면 모른다 | 이장과 무관하게 접근 가능한 경로가 있다 |
