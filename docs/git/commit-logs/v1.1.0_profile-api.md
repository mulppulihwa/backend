# v1.1.0 - profile API

**Date:** 2026-05-23
**Author:** Banu
**Version:** v1.1.0
**Branch:** feature/v1.1.0/profile-api

## What
`GET /api/profile/` 조회, `PATCH /api/profile/` 수정 API 추가.
필수 필드(region_code, birth_date, occupation_tags) 모두 입력 시 `profile_completed` 자동 업데이트.

## Why
- 프론트엔드 온보딩 폼 완료 후 프로필 저장 API 필요
- `profile_completed` 플래그가 정책 매칭 API 진입 조건 — 자동 업데이트 필요

## Implementation

### ProfileView (`apps/users/views.py`)
- `GET` — `UserProfileSerializer`로 프로필 반환
- `PATCH` — partial update. 저장 후 `region_code`, `birth_date`, `occupation_tags` 모두 채워지면 `profile_completed=True` 자동 set

### URL 분리 (`apps/users/urls.py`)
- `auth_urlpatterns` — `/api/auth/kakao/`, `/api/auth/token/refresh/`
- `profile_urlpatterns` — `/api/profile/`

### config/urls.py
- `api/profile/` → `profile_urlpatterns` 연결

## Endpoints
- `GET /api/profile/` — 프로필 조회 (인증 필요)
- `PATCH /api/profile/` — 프로필 수정 (인증 필요), partial update

## Result
- Django system check 통과 ✅
- profile_completed 자동 업데이트 로직 포함 ✅
