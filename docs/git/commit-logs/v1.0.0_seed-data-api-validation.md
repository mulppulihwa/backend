# v1.0.0 - regions & policies seed data, API validation

## What
v1 운영에 필요한 기본 데이터(지역, 정책)를 시드하고, API 엔드포인트 동작을 확인했음.

## Why
- 지역 코드(regions) 없으면 정책 매칭이 작동 불가
- 정책 데이터 없으면 사용자 대면 기능 테스트 불가
- API가 실제로 동작하는지 통합 검증 필요

## Implementation
1. **Regions Management Command** (`apps/regions/management/commands/seed_regions.py`)
   - 광역 17개 (시도)
   - 충청북도 11개 시군구 (옥천군 포함)
   - 총 28개 지역 추가

2. **Policies Management Command** (`apps/policies/management/commands/seed_policies.py`)
   - 귀농인 정착자금, 귀촌인 주택 구입, 청년 귀농, 농업인 교육, 옥천군 정착 장려금
   - 총 5개 정책 (다양한 benefit_type, 마감일 분포)

3. **API 검증**
   - `GET /api/policies/preview/` → ✅ 정책 3개 반환
   - `GET /api/docs/` → ✅ Swagger UI 로드
   - `GET /api/schema/` → ✅ OpenAPI 스키마 제공

## Result
- Server 정상 시작 (`python manage.py runserver`)
- 비로그인 사용자도 정책 미리보기 가능
- 매칭/파싱 API는 인증/권한 설정 완료 (구현 검증 대기)
