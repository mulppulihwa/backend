**Date:** 2026-05-24
**Author:** Banu
**Version:** v1.3.0
**Branch:** feature/v1.3.0/diagnosis-service

## What
온보딩 완료 처리 로직을 `lib/diagnosis_service.py` Facade로 추출.

## Why
- `profile_completed` 업데이트 로직이 `ProfileView.patch()`에 인라인으로 있어 재사용 불가
- 향후 온보딩 완료 시 추가 처리(정책 매칭 등) 확장을 위한 단일 진입점 필요

## Implementation

### `lib/diagnosis_service.py` (신규)
- `REQUIRED_FIELDS` — 온보딩 완료 판단 기준 필드 정의
- `is_profile_complete(profile) -> bool` — 필수 필드 충족 여부 반환
- `sync_profile_completed(user) -> bool` — profile_completed 갱신, 변경 시 True 반환

### `apps/users/views.py`
- `_REQUIRED_FIELDS` 상수 및 인라인 완료 판단 로직 제거
- `ProfileView.patch()`에서 `sync_profile_completed(request.user)` 호출로 교체

## Result
- Django system check 통과 ✅
