## What
프로젝트 전체 레포지토리에 `.gitignore` 파일을 추가하여 민감 정보, 빌드 결과물, IDE 캐시 등이 실수로 커밋되지 않도록 방지.

## Why
- `.env` 파일에 API 키(Anthropic, 복지로, 카카오 Client Secret 등) 포함
- Python 가상환경, `__pycache__`, pytest 캐시 등이 git에 추적되면 레포 오염
- IDE 설정(`.vscode`, `.idea`), 임시 파일(`*.swp`) 등을 제외하여 깔끔한 히스토리 유지
- Node modules (프론트) 미포함 시 배포 시간 단축

## Implementation
`.gitignore` 추가:
```
# Environment
.env, .env.local, .env.*.local

# Python
__pycache__/, *.pyc, venv/, .pytest_cache/, .coverage

# IDE
.vscode/, .idea/, *.swp, .DS_Store

# Django
*.log, db.sqlite3, /staticfiles/, /media/

# Node (frontend)
node_modules/, .next/, out/

# CI/CD
.github/workflows/*.log
```

## Result
- 민감 정보 커밋 방지 ✅
- 불필요한 파일 추적 제거 ✅
- 개발자 환경별 설정 충돌 방지 ✅
