## What
유저가 정책을 저장하고 상태를 관리하는 API 3개 추가.

## Endpoints
- `GET  /api/users/me/policies/` — 저장된 정책 목록
- `POST /api/users/me/policies/{id}/save/` — 정책 저장 (중복 저장 시 200)
- `PATCH /api/users/me/policies/{id}/status/` — 상태 변경 (신청예정 / 신청완료 / 관심없음)

## Why
- 유저가 관심 정책을 저장하고 신청 상태를 추적할 수 있어야 함
- UserPolicy 모델은 v1에서 이미 정의됨 — API만 없었던 상태

## Implementation

### UserPolicySerializer (`apps/users/serializers.py`)
- policy 정보(title, amount_text, benefit_type, apply_end_date) 함께 반환

### 3개 뷰 (`apps/users/views.py`)
- `UserPolicyListView` — profile 기준 목록, select_related로 N+1 방지
- `UserPolicySaveView` — get_or_create로 중복 저장 안전 처리
- `UserPolicyStatusView` — Status.values 검증 후 update_fields로 저장

### URL (`apps/users/urls.py`, `config/urls.py`)
- `user_policy_urlpatterns` 분리, `/api/users/me/policies/` 에 연결
