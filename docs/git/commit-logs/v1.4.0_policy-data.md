# v1.4.0 - policy data

**Date:** 2026-05-27
**Author:** Banu
**Version:** v1.4.0
**Branch:** feature/v1.4.0/policy-data

## What
귀농귀촌 실 정책 12개 픽스처 등록 + Admin AI 파싱 액션 추가.

## Why
- 실제 정책 데이터 없이는 매칭 파이프라인(v1.3.0) 테스트 불가
- Django Admin에서 공고문 원문 → AI 자동 파싱 워크플로우 필요

## Implementation

### `apps/policies/models.py`
- `raw_text = TextField(blank=True)` 필드 추가 — Admin에서 공고문 원문 저장용

### `apps/policies/migrations/0002_add_raw_text_to_policy.py`
- raw_text 필드 마이그레이션

### `apps/policies/admin.py`
- `parse_from_text` Admin action 추가: 선택된 Policy의 `raw_text`를 `parse_policy()`에 넘겨 자격 조건 자동 추출 후 저장
- `fieldsets` 구성으로 편집 화면 섹션화 (기본정보 / 자격조건 / 신청정보 / AI파싱 / 메타)
