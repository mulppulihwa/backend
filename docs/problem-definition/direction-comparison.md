# 방향 A vs B 비교 분석 — 물뿌리화 팀 (2026.04.10 업데이트)

> 팀이 A(귀향인 온보딩)와 B(대학생 촌캉스 + 청소년 진로 탐색) 사이에서 결정을 못 하고 있는 상황.
> 초기 분석에서는 A가 유리하다고 봤으나, 각 방향의 실질적 걸림돌을 직면하면서 결정이 어려워졌다.
> 이 문서는 양쪽의 강점과 **실행 리스크**를 함께 정리한다.

---

## ⚠️ 현재 걸리는 문제들 (2026.04.10 기준)

### 방향 A (귀향인 온보딩)의 실행 리스크

**문제정의는 깔끔하다. 그런데 실행에서 두 가지가 걸린다.**

1. **이장님 의존성 문제**
   - 서비스 구조가 이장님을 통해 마을 지식을 수집하는 것에 크게 의존
   - 현실: 이장님들도 고령층이며, 디지털 도구를 능숙하게 다룰 수 있는지 검증이 안 됐음
   - 이장님이 협조하지 않거나, 중간에 교체되거나, 디지털 참여가 어렵다면 → 수집 루프 자체가 끊어짐
   - "이장 한 명에게 의존하지 않는 구조"를 만드는 게 문제 정의인데, **우리 서비스도 이장 한 명에게 의존하는 역설**

2. **구전 데이터 수집 문제**
   - 수십 년간 사람 사이에서 구전(口傳)으로만 전해진 마을 암묵지를 어떻게 데이터로 전환할 것인가
   - 인터뷰로 캐낼 수 있는 양과 질의 한계가 있음
   - 이장님이 말해주지 않으면 아무것도 남지 않는 구조 — 데이터 소스가 단일점(single point)

**결론: 문제 정의는 날카롭지만, 초기 데이터 확보 경로가 취약하다.**

---

### 방향 B (교육/관광)의 방향 모호성

**솔루션의 완성도는 있다. 그런데 방향 자체가 아직 갈리지 않았다.**

- 현재 방향 B는 **"대학생 촌캉스"**(농촌 체류 + 지역 연계 경험) + **청소년 진로 탐색**이 합쳐진 형태
- 그런데 이 둘은 성격이 다르다:

| | 교육 (청소년 진로) | 관광 (촌캉스/체험) |
|---|---|---|
| 주요 타겟 | 농촌 청소년, 대학생 멘토 | 도시 대학생, 외지인 |
| 지역소멸 기여 방식 | 장기적 — 인식 전환, 로컬 커리어 확장 | 단기적 — 외부 인구 유입, 경제 활성화 |
| 임팩트 경로 | 느리지만 구조적 변화 | 빠르지만 일회성 효과 |
| 솔루션 성숙도 | 비교적 구체적 | 아직 정의 중 |

- 관광(촌캉스)은 단기 유입 → **경제 활성화** 측면에서 지역에 직접 도움이 될 수 있음
- 교육은 **솔루션의 형태**는 잡혀있지만, 장기 임팩트라 검증이 느림
- **두 갈래를 동시에 잡으면 집중력이 흐트러진다**

**결론: 솔루션의 완성도는 괜찮지만, 교육이냐 관광이냐를 먼저 결정해야 다음으로 갈 수 있다.**

## 1. 문제가 얼마나 깊이 파고들 수 있는가

### 방향 A — 귀향인 온보딩

표면적 문제: "귀향인이 정보를 못 찾는다"
한 단계 깊이: "이장 한 사람에게 마을 운영 지식이 집중되어 있다"
**가장 깊은 층위:**

> 마을이 새 구성원을 받아들이기 위해 필요한 지식 — 누구한테 연락해야 하는지, 어떤 불문율이 있는지, 어떤 이웃이 어떤 도움을 줄 수 있는지 — 이 모든 암묵지(tacit knowledge)가 오직 사람과 사람 사이의 구두 관계에만 존재한다. 이 구조에서 이장이 바뀌거나 고령화되면, 마을 운영 지식 자체가 사라진다.

**핵심 인사이트**: 지역소멸은 인구가 줄어서가 아니라, 마을을 유지하는 암묵지가 전승되지 않아서 일어난다.
이 프레임으로 문제를 정의하면, 온보딩 앱이 아니라 **마을 지식 보존 및 전달 인프라**가 된다. 완전히 다른 서비스다.

### 방향 B — 청소년 진로 탐색

표면적 문제: "학생들이 진로 정보가 없다"
한 단계 깊이: "비교 기준이 없어 선택지를 좁게 인식한다"
**가장 깊은 층위:**

> 농촌 학생의 진로 상상력이 지리적으로 제한된다.

여기서 더 내려가기가 어렵다. 이미 교육 불평등, 지역 격차 담론과 겹치는 영역이고, 문제 자체는 오래됐다. "비교 기준 부재"는 날카로운 재정의이지만 그 아래로 내려가면 결국 "정보 접근성" 문제로 수렴된다.

**판정: A가 더 깊다.** A의 핵심 인사이트는 기존에 아무도 이 방식으로 정의하지 않은 문제다.

## 2. 비슷한 서비스가 얼마나 있는가 (경쟁 지도)

### 방향 A 경쟁 지도

| 서비스 | 무엇을 하는가 | 무엇을 못 하는가 |
|---|---|---|
| 그린대로 (greendaero.go.kr) | 귀농귀촌 정책·정보 포털 (550만 건+) | 면 단위 생활 밀착 정보 없음. 정책 정보만. |
| 귀농귀촌종합센터 (returnfarm.com) | 멘토 매칭, 교육, 상담 | 온라인 정보만. 마을 진입 이후 공동체 적응 지원 없음 |
| 지자체 귀농귀촌 지원센터 | 자금·주거 지원 | 관계 형성, 일상 생활 지식 전달 없음 |

**경쟁 공백**: 면 단위 이하의 일상 생활 지식, 이웃 관계, 마을 불문율, 실제 정착에 필요한 비공식 정보를 다루는 서비스가 전혀 없다. 스타트업도 없다. 정부가 만든 것들은 전부 macro 레벨 정책 정보다.

### 방향 B 경쟁 지도

| 서비스 | 무엇을 하는가 | 무엇을 못 하는가 |
|---|---|---|
| 점프(JUMP) | 대학생 멘토링 NGO (누적 2.6만 명+), 농촌 확장 중 | 이미 농촌으로 확장 중. 우리가 하려는 것과 직접 겹침 |
| 꿈드림 | 정부 진로 지원 (만 9~24세), 전국 센터 운영 | 청산면에도 적용 가능한 인프라가 이미 존재 |
| 달꿈(dalkkum.com) | 진로 멘토링 ed-tech 플랫폼 | 농촌 특화는 아니지만 기능상 겹침 |
| 지역아동센터 | 방과후 진로 탐색 모듈 운영 | 청산면 센터가 이미 존재 |

**경쟁 현황**: 포화 상태다. 점프는 이미 농촌으로 확장 중이고, 꿈드림은 정부 인프라로 이미 깔려있다. 우리가 B 방향으로 가면 이미 있는 것들과 싸워야 한다.

**판정: A의 경쟁 공백이 압도적으로 크다.**

## 3. 실제로 실행 가능한 서비스인가

### 방향 A

- 청산면이라는 구체적인 지역에서 귀향인 인터뷰 2~3건이면 문제 검증 가능
- 황민호 대표님이라는 연결 고리가 이미 있다
- 이장 인터뷰가 시스템 이해의 핵심이고, 접촉 가능
- 초기 MVP: 귀향인을 위한 청산면 생활 가이드 (디지털 또는 종이) → 반응 보고 고도화
- 한 학기 안에 작동하는 프로토타입 만들기 충분히 가능

### 방향 B

- 학생 인터뷰부터 다시 해야 한다 (고등학생 미인터뷰)
- 멘토(대학생) 공급도 검증 안 됐다
- 기존 아동센터·학교와의 협력 없이는 운영 불가
- JUMP 같은 기존 조직이 이미 같은 공간에서 더 많은 자원으로 움직이고 있다
- 차별화 포인트를 만들기 어렵다

**판정: A가 실행 속도와 차별화 가능성 모두 높다.**

## 4. 기술로 얼마나 발전시킬 수 있는가 (기술 천장)

### 방향 A — 기술 개발 로드맵

**1단계 — 마을 지식 수집**
- 귀향인 인터뷰·이장 인터뷰를 구조화된 데이터로 축적
- "청산면 생활 위키" — 마을 암묵지를 처음으로 텍스트화
- 기술 수준: 큐레이션 + 검색

**2단계 — 지식 그래프화**
- 마을 구성원·장소·사건·규칙이 연결된 지식 그래프 구축
- 예: "농기계 빌리려면 → 김○○ 이웃 → 3월 파종 전엔 바쁨 → 연락 시점 중요"
- 기술 수준: 그래프 DB + 관계 추론

**3단계 — AI 기반 온보딩 어시스턴트**
- 귀향인이 질문하면 축적된 마을 지식 기반으로 답변 (RAG 구조)
- "이 마을에서 처음 3개월 안에 해야 할 일" 개인화 제공
- 기술 수준: LLM + 로컬 지식 RAG

**4단계 — 정착 패턴 분석**
- "잘 정착한 귀향인 vs 떠난 귀향인"의 초기 3개월 행동 패턴 비교
- 정착 리스크 조기 감지 → 선제적 개입
- 기술 수준: 패턴 분석 + 예측 모델

**5단계 — 전국 확장**
- 청산면 모델을 다른 면 단위로 확장
- 한국 전체 면 단위(900개+)가 잠재 시장
- 각 마을의 지식 그래프가 쌓일수록 데이터 해자(moat) 형성
- 장기: 사라져가는 농촌 공동체 지식의 전국적 아카이브

**기술 천장**: 매우 높다. 이 문제를 완전히 풀려면 커뮤니티 지식 AI + 사회적 매칭 + 예측 모델이 모두 필요하다. 기술이 깊어질수록 경쟁자가 따라오기 어려운 데이터 자산이 쌓인다.

### 방향 B — 기술 개발 로드맵

**1단계** — 멘토-학생 매칭 플랫폼
**2단계** — 농어촌전형 정보 DB + 전략 가이드
**3단계** — 비동기 영상 멘토링
**4단계** — 진로 경로 시각화

**기술 천장**: 낮다. 매칭 알고리즘, 비디오 멘토링, 진로 추천 — 이미 ed-tech에서 수십 개 팀이 만든 것들이다. 기술적 차별화 포인트를 만들기가 어렵고, 데이터 해자도 없다.

**판정: A의 기술 천장이 B보다 압도적으로 높다.**

## 6. 방향 A로 갔을 때 뾰족한 문제 정의

지금 버전의 문제 정의는 아직 뭉뚝하다. 진짜 날카로운 버전은 이것이다:

> **청산면에 새로 이주한 귀향인**이 **마을 공동체의 일원으로 뿌리내리기** 위해서는,
> **현재 이장 한 사람의 머릿속에만 존재하는 마을 운영 암묵지가 체계적으로 기록되고 전달되는 구조**가 해결되어야 한다.

이것이 왜 혁신적인가:
- "정보 부족" 문제가 아니라 **"지식 구조" 문제**다
- 이 문제를 풀면 마을이 새 사람을 받을 수 있는 능력 자체가 생긴다
- 지역소멸을 "인구 유입"이 아니라 "공동체 지식 보존"으로 접근하는 유일한 프레임
- 서비스가 쌓을수록 그 마을의 살아있는 DNA가 된다

## 결론: 결정을 막는 구조를 먼저 해결해야 한다

### 왜 결정이 어려운가

| | 방향 A (귀향인 온보딩) | 방향 B (교육/관광) |
|---|---|---|
| 강점 | **문제 정의가 깔끔하다** | **솔루션의 형태가 괜찮다** |
| 약점 | **실행 경로가 취약하다** (이장 의존, 구전 데이터) | **방향 자체가 갈리지 않았다** (교육 vs 관광) |

- A는 "무엇을 푸는가"는 명확한데 "어떻게 첫 데이터를 만드는가"가 막혀있다
- B는 "어떻게 실행할지"는 보이는데 "무엇을 풀기로 했는가"가 아직 흐릿하다

### 다음 질문을 먼저 결정해야 한다

**방향 A를 계속 가려면:**
- 이장님 없이 마을 암묵지를 수집할 수 있는 대안 경로가 있는가?
  (예: 귀향인 직접 수집, 청산면 내 다른 중간자, 주민 참여형 위키)
- 이장님과의 협력 구조를 어떻게 설계하면 단일 의존점을 줄일 수 있는가?

**방향 B를 계속 가려면:**
- 교육과 관광 중 하나를 먼저 선택할 것 — 동시에 두 방향은 안 된다
- 관광(촌캉스)으로 간다면: 단기 유입 → 경제 활성화에 집중, 교육적 요소는 부가
- 교육으로 간다면: 장기 임팩트, 청소년 인식 전환에 집중, 빠른 검증이 어려움을 감수

### 팀이 지금 당장 해야 할 것

1. **방향 B라면**: 교육 vs 관광 중 하나를 팀이 먼저 결정한다. 이건 인터뷰로 알 수 있는 게 아니라 팀의 방향 선택이다.
2. **방향 A라면**: 이장님을 통하지 않고 마을 암묵지를 확보할 수 있는 경로를 2~3가지 나열하고 검증 가능한지 확인한다.
3. 어느 쪽이든 — 다음 필드 인터뷰에서 이 리스크를 직접 건드려야 한다. 계속 "가능성"으로만 두면 결정이 더 늦어진다.
