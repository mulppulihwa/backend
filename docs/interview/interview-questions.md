# 인터뷰 질문지 (2026.04.09)

> 문제 정의 근거: `docs/problem-definition/problem-definition-v4.md`
> 원칙: "우리 서비스가 필요하죠?" 형태의 유도 질문 금지. 가설/사실 검증 중심.

태그 형식: `[주제]` `→ 얻고 싶은 것`

## 교육 그룹 — 공통 질문 5개

> 검증 목표: **"비교 기준 부재"를 학생/교사가 실제로 문제로 인식하는가, 아니면 인식하지 못하는가**

1. 청산 학생들이 졸업 후 주로 어디로 가나요? 그 흐름이 몇 년 새 달라진 게 있나요?
   `[진로 현황]` → 학생들이 실제로 어떤 선택지를 고르고 있는지 베이스라인 파악

2. 진로 이야기를 꺼낼 때 학생들이 자주 쓰는 말이 뭔가요?
   `[학생 언어]` → 팀의 용어(비교 기준 부재 등)가 아닌 당사자 언어로 문제를 표현하는지 확인

3. 진로 정보를 주로 어디서 얻어요? — 선생님, 부모님, 인터넷, 유튜브, 아니면 다른 데서요?
   `[정보 접근 경로]` → 기존 채널의 실태 파악 + 정보 격차가 구조적인지 개인적인지 판단

4. "서울 애들이랑 나는 다르다"거나 "여기선 불리하다"는 생각을 해본 적 있어요?
   `[비교 기준 인식]` → 가설 직접 검증: 불리함을 인식하는가 vs 인식 자체가 없는가

5. 도움을 받고 싶을 때 제일 먼저 떠오르는 사람이나 방법이 뭔가요?
   `[지원 네트워크]` → 멘토 공백이 실제로 있는지, 있다면 어디서 느끼는지 확인

### 김두호 (고3, 충북대/교원대 희망) — 개인 질문 5개

1. 저번에 교원대 얘기 했잖아요 — 그 목표를 어떻게 정하게 됐어요? 누가 알려줬나요, 스스로 찾은 건가요?
   `[진로 결정 경위]` → 정보 접근 경로가 우연인지 구조적인지, 외부 도움이 있었는지 확인

2. 그 학교에 어떻게 준비해야 하는지는 어떻게 알았어요?
   `[입시 정보 접근]` → 정보를 혼자 찾았는지, 도움을 받았는지 — 정보 격차 실재 여부

3. 농어촌전형이라고 들어봤어요? 어떻게 알게 됐어요?
   `[농어촌전형 인지]` → 핵심 제도를 알고 있는지, 알았다면 어떤 경로로 — 정보 전달 구조 파악

4. 친구들이랑 진로 얘기할 때 주로 어떤 이야기가 나와요?
   `[또래 진로 분위기]` → 개인 사례가 아닌 집단 분위기로 비교 기준 부재를 간접 확인

5. 진로 준비하면서 "이걸 더 일찍 알았으면 달랐을 텐데" 싶은 게 있어요?
   `[정보 격차 체감]` → 학생 스스로 정보 부재를 문제로 인식하는지 직접 확인

6. 공부나 진로 관련해서 알고 싶은데 물어볼 사람이 없어서 막막했던 적 있어요?
   `[멘토 공백 체감]` → 정보 격차를 구체적 상황으로 확인 — "막막하다"는 표현이 나오는지

7. 농어촌전형 써볼 생각은 있어요? 준비하려면 뭐가 필요할 것 같아요?
   `[제도 활용 의향]` → 인지에서 실행 사이 장벽이 뭔지 — 정보 부족인지 다른 이유인지

8. 대학생이 방학에 여기 와서 공부 도와주거나 진로 얘기 해주면 관심 있어요? 실제로 쓸 것 같아요?
   `[솔루션 반응]` → 멘토링 모델에 대한 직접 반응 테스트 — 마지막에 묻기

### 전용현 교사 — 개인 질문 5개

1. 학생들이 진로 고민을 털어놓는 편인가요? 보통 어떤 이야기를 하나요?
   `[학생 발화 수집]` → 교사 해석이 아닌 학생이 실제로 꺼내는 언어와 주제 파악

2. 청산 학생들의 진학 결과가 도시 학생들이랑 비교해서 어떻게 다른 것 같으세요?
   `[격차 실재 여부]` → 교사 시각에서 본 구조적 불리함이 있는지 — 온정주의 필터 주의

3. 학생들 중에 외부 선배나 대학생한테 진로 조언을 받아본 케이스가 있나요?
   `[외부 멘토 경험]` → 멘토링 수요가 실재하는지, 있다면 어떤 형태였는지

4. 농어촌전형을 적극 활용하는 학생과 그렇지 않은 학생 사이에 차이가 있나요? 어떤 차이요?
   `[제도 활용 격차]` → 같은 제도도 활용 여부가 갈리는 원인 파악 — 정보 vs 의지 vs 환경

5. 선생님이 진로 지도할 때 가장 한계를 느끼는 순간이 언제인가요?
   `[공급자 한계]` → 현재 시스템의 빈틈을 교사 입장에서 확인 — 솔루션 방향 힌트

6. 외부에서 대학생이 와서 멘토링해주는 프로그램이 생긴다면 학교에서 수용 가능한 공간·일정이 있나요?
   `[멘토링 수용 가능성]` → 솔루션 실현 가능성 검증 — 공급자(교사/학교) 입장에서의 현실적 조건

7. 학부모들이 자녀 교육에 대해 가장 많이 하는 말이 뭔가요?
   `[학부모 관점]` → 교육 의사결정자의 실제 관심사 파악 — 학생 발화와 부모 발화의 차이 확인

## 온보딩 그룹 — 공통 질문 5개

> 검증 목표: **정착 실패 원인이 정보 부족인가, 관계 형성 실패인가 — 그리고 기존 채널이 정말 충분한가**

1. 청산에 새로 이사온 분들이 정착하는 걸 가까이서 보신 적 있으세요? 어떠셨나요?
   `[관찰 경험]` → 응답자가 실제 사례를 갖고 있는지 확인 + 자연스럽게 열기

2. 잘 정착한 분이랑 그렇지 않은 분 사이에 어떤 차이가 있는 것 같으세요?
   `[Bright Spots 역추적]` → 정착 성공 요인이 정보인지 관계인지 성격인지 — 렌즈 4·5 검증

3. 새로 온 분들이 가장 어려워하는 게 뭐라고 느끼세요?
   `[정착 장벽]` → 정보 부족 vs 관계 형성 vs 기타 — 관찰자 시각에서 원인 파악

4. 새 주민이 마을 정보를 얻을 수 있는 경로가 지금 뭐가 있다고 생각하세요?
   `[기존 채널 인식]` → 부면장의 "기존 채널로 충분하다" 반박을 다른 응답자로 교차 검증

5. 마을에서 새로 온 분이 언제 "정착했다"는 느낌이 드는 것 같아요?
   `[정착 기준]` → 정착의 실질적 의미가 정보 습득인지 관계 형성인지 — 솔루션 방향 결정

### 고재환 청산면장 — 개인 질문 5개

1. 청산면에 귀농귀촌 오시는 분들이 매년 어느 정도 되나요? 다시 떠나시는 분은요?
   `[이탈률 실태]` → 문제의 규모 파악 + 행정이 이탈을 인지하고 있는지

2. 면사무소 차원에서 새 주민에게 제공하는 정착 안내가 어디까지 있나요?
   `[행정 온보딩 현황]` → 기존 공식 채널의 실제 범위 확인 — 공백이 어디서 생기는지

3. 이장님마다 새 주민 안내 방식이 다른 편인가요? 그게 문제가 된 적 있나요?
   `[이장 편차]` → 사실로 정의된 "이장 편차" 가설을 행정 책임자에게 직접 검증

4. 귀농귀촌인이 면사무소에 가장 많이 문의하는 게 뭔가요?
   `[실제 수요]` → 신규 이주자가 실제로 모르는 것이 무엇인지 행정 데이터로 확인

5. 청산에서 귀농귀촌인이 잘 정착하려면 지금 뭐가 가장 부족하다고 보세요?
   `[행정 인식]` → 면장이 문제를 인식하고 있는지, 어떻게 프레이밍하는지 — 협력 가능성 탐색

6. 전입 서류나 팸플렛 외에 새 주민에게 별도로 제공하는 정착 안내가 있나요?
   `[공식 채널 범위]` → 행정 채널이 실제로 어디까지 커버하는지 — 공백 구간 파악

7. 이장님을 통한 구두 전달 외에 다른 공식 채널이 있나요?
   `[채널 다양성]` → 단일 채널(이장) 의존도 확인 — 편차 문제의 구조적 원인

### 한영순 (다시 돌아온 청년) — 개인 질문 5개

1. 청산에 다시 돌아오기로 결심한 계기가 뭔가요?
   `[귀환 동기]` → 귀향을 밀어붙인 요인 파악 — 정보보다 관계/감정적 요인이 더 컸는지

2. 처음 정착할 때 가장 막막했던 게 뭔가요? 그걸 어떻게 해결했어요?
   `[정착 장벽 + 해결 경로]` → 정보 부족이었는지 관계 형성이었는지 + 실제 해결 방법

3. 도움이 됐던 사람이나 정보 채널이 있었나요? 그게 어떻게 연결됐어요?
   `[Bright Spots 경로]` → 잘 정착한 사람의 성공 경로 — 재현 가능한 요소가 있는지

4. "이걸 미리 알고 왔으면 훨씬 쉬웠을 텐데" 싶은 게 있어요?
   `[정보 공백 체감]` → 당사자가 직접 표현하는 정보 부재 — 가장 신뢰도 높은 데이터

5. 지금 잘 살고 있다면, 그 이유가 뭐라고 생각하세요?
   `[성공 귀인]` → 본인 귀인이 정보인지 관계인지 성격인지 — 렌즈 4 vs 5 판별

6. 이장님한테는 어떻게 연락했나요? 처음에 접근하기 어렵지는 않았나요?
   `[이장 접근성]` → 이장이 실제 온보딩 허브 역할을 하는지, 접근 장벽이 있는지

7. 마을 행사나 공동작업에 처음 참여할 때 어떤 기분이었나요? 어떻게 참여하게 됐어요?
   `[공동체 진입 경험]` → 관계 형성의 실제 계기 파악 — 정보 제공보다 관계 연결이 핵심인지

8. 힘들었을 때 떠날 생각을 한 적 있나요? 그 이유가 뭔가요?
   `[정착 의지 임계점]` → 떠나게 만드는 요인이 정보 부족인지 관계 실패인지 — 렌즈 4 직접 검증

9. 지금 여기 계속 살 것 같으세요?
   `[지속 가능성]` → 현재 정착 상태가 안정적인지 + 남아있는 이유가 무엇인지

### 김련희 (일반 주민) — 개인 질문 5개

1. 청산에 얼마나 사셨어요? 새로 이사온 이웃들을 많이 보셨겠네요.
   `[관찰 기반 확인]` → 장기 거주자로서 신규 이주자 변화를 목격한 경험 있는지 확인

2. 새 이웃이랑 처음에 어떻게 가까워지게 됐어요? 계기가 있었나요?
   `[관계 형성 메커니즘]` → 기존 주민 입장에서 연결이 어떻게 이루어지는지 — 구조적 계기 vs 우연

3. 새로 온 분이 오래 못 버티고 떠나는 걸 보신 적 있어요? 왜 떠났다고 생각하세요?
   `[이탈 원인 관찰]` → 주민 시각에서 본 정착 실패 원인 — 정보 부족 vs 관계 실패 vs 다른 것

4. 마을 소식이나 필요한 정보는 주로 어디서 어떻게 얻으세요?
   `[정보 채널 실태]` → 기존 주민이 실제로 쓰는 채널 파악 — 신규 이주자가 접근 가능한지

5. 새로 온 분이 마을에 익숙해지려면 제일 먼저 뭐가 필요하다고 느끼세요?
   `[정착 조건 인식]` → 정보 vs 관계 vs 다른 요소 — 일반 주민이 보는 핵심 장벽

### 김미영 청산우체국장 — 개인 질문 5개

1. 우체국에 새로 이사오신 분들이 오는 경우가 있나요? 보통 어떤 용건으로 오세요?
   `[신규 이주자 접점]` → 우체국이 실제로 온보딩 접점이 되는지, 어떤 니즈로 오는지

2. 처음 와서 모르거나 헤매는 걸 자주 보세요? 주로 어떤 것들인가요?
   `[정보 공백 목격]` → 신규 이주자가 실제로 모르는 것의 구체적 내용 — 현장 관찰 데이터

3. 주민들 사이에 정보가 도는 주요 경로가 어디라고 느끼세요?
   `[정보 흐름 구조]` → 마을 정보 채널의 실태 파악 — 이장 외에 다른 허브가 있는지

4. 잘 정착한 분이랑 그렇지 않은 분 차이를 우체국에서도 느끼신 적 있어요?
   `[정착 격차 관찰]` → 제3자 시각에서 본 정착 성공/실패 차이 — 정보 vs 관계 단서

5. 새 주민이 마을에 연결되는 과정에서 우체국이 어떤 역할을 하고 있다고 생각하세요?
   `[우체국 역할 인식]` → 우체국이 온보딩 허브가 될 수 있는지 가능성 탐색 — 솔루션 힌트
