# 지역소멸 문제 맥락 리서치

**날짜**: 2026-04-08

## 목적

팀이 필드트립과 인터뷰를 통해 감지한 문제들이 실제 데이터와 얼마나 일치하는지 검증한다.
귀농귀촌 정착 실패, 농촌 정보 전달 구조, 교육 격차 세 가지 영역을 중심으로 분석한다.
문제 정의 정밀화와 솔루션 방향 결정에 참고한다.

---

## 1. 지역소멸 현황

### 전국 현황 (2024~2026)

- 전국 229개 기초자치단체 중 **138곳(60.2%)** 소멸위험지역 (2026년 2월 기준)
- 신규 확산 중: 2024년 광역시 구·군(부산, 대구, 대전, 울산)까지 진입
- 인구소멸은 지방 농촌만의 문제가 아니라 도시 외곽으로 확산 중

**출처**: 한국고용정보원 《지방소멸 2024: 광역대도시로 확산하는 소멸위험》(2024)

### 옥천군 데이터

- 옥천군 소멸위험지수 **0.181** → '소멸고위험' 분류
- 옥천군 인구 **48,373명** (2025년 9월 기준)
- 청산면 소멸위험지수 0.1 미만으로 추정 (읍 단위보다 면 단위가 심각)

### 구조적 원인 (수치 이면)

악순환 메커니즘:
```
일자리 부족 → 청년 유출 → 고령화 심화 → 소비 수요 감소 → 상점·시설 폐쇄 → 삶의 질 하락 → 추가 유출
```

- 인구이동이 출산율보다 더 결정적인 변수
- 제조업 쇠퇴(2010년대 이후)로 비수도권 일자리 구성 악화

## 2. 귀농귀촌 정착 실패

### 통계와 현실의 괴리

| 구분 | 수치 | 출처 |
|---|---|---|
| 공식 역귀농률 (귀농인) | 3.6% | 통계청 《2024년 귀농어·귀촌인통계》 |
| 공식 역귀촌률 | 8.5% | 동일 |
| 장기추적조사 역귀농률 | 8.6% | 한국농촌경제연구원 (2014~2018) |
| 현장 추정치 | **30% 이상** | 현장 전문가 추정 |

→ **공식 통계와 현실 사이에 3~4배 차이** 존재. 황 대표님의 "귀농귀촌인 정착 실패 심각" 발언을 데이터가 지지한다.

### 정착 실패의 실제 원인 (당사자 기준)

1. **공동체 적응 실패** (가장 결정적)
   - 텃세, 배타성, 가부장적 문화
   - 도시식 개인 생활 방식 인정받지 못함
   - 연고 없는 외부인에게 비공식 정보 비공유

2. **정보 접근 실패**
   - 마을 공동작업 일정·규칙, 비공식 노동시장, 영농 노하우
   - 이웃 관계망에 편입되기 전에는 접근 불가능한 정보들

3. **경제적 어려움**
   - 귀농 후 소득 발생까지 3~5년 소요
   - 그 사이 초기 투자금 원리금 상환 부담

**성공 vs 실패의 결정 요인**: 소득보다 **공동체 수용성**이 더 중요.

**출처**: 농림축산식품부 《귀농귀촌 실태조사》(2023), 한국농촌경제연구원 장기추적조사

## 3. 농촌 정보 전달 구조의 문제

### 이장 중심 구조의 구조적 한계

- 이장의 역할 정의 모호 → 역량·태도에 따라 정보 전달 품질 편차 심각
- 구두 전달은 기록 없음 → 확인 불가, 책임 소재 불명확
- 이장 개인 판단으로 정보 선별·왜곡 가능

→ 황 대표님의 "이장 편차 문제" 발언을 구조적으로 확인.

### 공식 채널 vs 실제 필요 정보의 갭

| 공식 채널이 제공하는 정보 | 귀농인이 실제 필요한 정보 |
|---|---|
| 행정공고, 지원사업 안내 | 마을 공동작업 일정·규칙 |
| 세금·복지 안내 | 비공식 노동시장 정보 |
| 홈페이지 게시 공문 | 영농 기술 노하우 |
| 이장이 선별한 공지 | 지역 선후배 네트워크 |

→ **부면장님의 "기존 채널로 충분하다" 주장은 기존 주민 관점에서만 옳다.** 귀농인 관점에서는 공백이 크다.

**출처**: 농어촌알리미 포털 현황 분석, KDI 《농촌지역의 정보화 실태와 정보격차 해소방안》

## 4. 농촌 교육 격차

### 현황 통계

- 농어촌 교육 만족도 **5.4점** vs 도시 **6.3점** (약 1.0점 차이, 10점 만점)
- 농어촌 초등학교 중 60명 이하 소규모 학교 비율: 충남 45.4%, 전남 53.5%
- 소규모 학교 문제: 선택 과목 개설 제한, 심화 학습 제공 어려움

**출처**: 한국농촌경제연구원 《농어촌 주민 정주 만족도 조사》(2024), 교육부 《2024 교육통계 연보》

### 농어촌특별전형 현황

- 2025학년도 기준 **5,721명 선발** (전체 모집인원의 82.4%)
- 지원 자격: 읍·면 지역 6년 이상 거주 + 재학 조건
- 입학정원의 4% 이내

**중요**: 전형 제도는 있지만, 제도를 알고 전략적으로 준비하는 학생과 그렇지 않은 학생 간 실질적 격차 존재.

### 기존 지원 프로그램의 한계

- 특별전형은 진학 기회 제공이지 교육 환경 개선이 아님
- 전문 교사 부족 + 순회 교사 제도 → 학생-교사 유대 약화 (교장선생님 발언과 일치)
- 학교 통폐합 → 통학 부담 + 지역 공동체 붕괴

## 5. 유사 서비스/사례 현황

### 귀농귀촌 온보딩 기존 서비스의 한계

| 서비스 | 내용 | 한계 |
|---|---|---|
| 그린대로 | 온라인 원스톱 정보 | 정보 전달만, 공동체 연결 없음 |
| 귀농귀촌종합센터 | 상담·정보 제공 | 참여율 낮음, 개인화 부족 |
| 지자체 상담센터 | 기술 정보 중심 | 생활정보 약함 |
| 체험 프로그램 | 최장 6개월 주거·연수비 | 단기 체험, 실제 정착 지원 부족 |

**공통 한계**: 귀농 전 정보 중심 / 귀농 후 적응 지원 약함 / 면·마을 단위 개인화 없음

### 마을 아카이빙 성공 사례

| 사례 | 특징 | 시사점 |
|---|---|---|
| 증평 아카이빙 프로젝트 (2019~) | 주민 주도 기록화 | 주민 참여·자치 가능 |
| 부산 산복도로 아카이브 | 장소·개인 스토리 수집 | 기록 단위는 사람과 장소 |
| 미추홀 시민아카이브 | 온라인 + 주민기록단 | 디지털 + 커뮤니티 병행 |

**성공 조건**: 주민 주도성 / 장기 지원 / 온오프라인 병행 / 지속 관리 체계
**공통 한계**: 기록 후 귀농자 온보딩 연계 미흡

## 사이드 이펙트 (리서치가 팀 판단에 미치는 영향)

### 인터뷰 검증 결과 업데이트

| 항목 | 팀 인터뷰 | 리서치 데이터 | 판단 |
|---|---|---|---|
| 귀농 정착 실패 심각 | 황 대표님 언급 | 현장 추정 30% | ✅ 강하게 지지됨 |
| 면 단위 정보 공백 | 황 대표님 언급 | 공식 채널 vs 생활정보 갭 확인 | ✅ 지지됨 |
| 이장 편차 문제 | 황 대표님 언급 | 구조적으로 확인 | ✅ 지지됨 |
| 기존 채널 충분 | 부면장님 주장 | 귀농인 관점에서는 공백 심각 | ❌ 기각 (부면장은 기존 주민 관점) |
| 대학생 멘토 부재 | 교장 언급 | 교육 자원 부족 데이터 일치 | ✅ 지지됨 |
| 학생 거주 만족도 높음 | 학생 인터뷰 | 교육 격차는 통계적으로 명백 | ⚠️ 주의 필요 (만족도 ≠ 기회 인식) |
| 학생 수도권 관심 낮음 | 학생 인터뷰 | 청년 수도권 집중은 전국적 추세 | ⚠️ 주의 필요 (인식과 현실 괴리 가능) |

### 부면장님 발언 재해석

"기존 채널로 충분하다"는 발언은 **기존 주민 관점에서만 유효**하다.
귀농귀촌인에게 이장 구두 전달 구조는 진입 장벽 그 자체다.
행정이 충분하다고 느끼는 것과 신규 이주자가 실제로 정보에 접근할 수 있는지는 다른 문제다.

### 학생 인터뷰 재해석

"버스 불편하지 않다", "여기 계속 살고 싶다"는 발언은 현재 삶에 대한 만족이지,
진로 선택지의 폭에 대한 인식이 아니다.
**비교 기준 자체가 없기 때문에 격차를 격차로 인식하지 못할 수 있다.**
